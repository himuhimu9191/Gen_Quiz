# バッチ051（JaQuAD候補3,500問）

JaQuADの固定コミットから **3,500問** を候補として追加しました。IDは `Q007001`〜`Q010500` です。問題文の短い行には記事名の文脈を補い、代表解答から「シリーズ」などの一般分類語を除き、Pykakasiで初期ひらがな読みを作りました。既存設問の正規化ハッシュとsource IDを照合し、衝突は取り込んでいません。

3,500問はすべて `candidate` で、出典本文との個別照合、正解範囲、表記ゆれ、読み、ジャンル・サブジャンル、難易度、タグ、人による承認は未完了です。短い設問652件は記事名を重ねないため短文のまま候補に残しました。難易度3は仮置きです。公開用のverified CSVには含めません。正規化した設問文とsource IDの重複は0件、設問に答えがそのまま含まれる候補は0件でした。回答の一致する組み合わせ304グループは意味が別かを個別確認する必要があります。元ファイルを再配布せず、固定コミット・ファイルハッシュ・回答位置をレビュー台帳に保存しています。

固定取得先を指定した再照合は次のコマンドで再実行できます。元設問、元回答、本文ハッシュ、回答位置、初期ひらがな読みの不一致を件数だけ返します。

```powershell
python scripts/audit_batch_051_jaquad.py --source-root "$env:TEMP\genquiz-jaquad-20261105"
```

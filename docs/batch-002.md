## Q000379 — エンタメ＆スポーツ / 音楽 / 難易度4

主となる音の直前などに小さく記し、符尾と符幹を斜線で横切って表す、短い前打音をイタリア語で何というでしょう？

## Q000380 — エンタメ＆スポーツ / 音楽 / 難易度5

## Q000385 — 社会 / 経済 / 難易度5

## Q000386 アニメ＆ゲーム / 難易度1

敵を吸い込む能力を持ち、コピー能力でさまざまな技を使う、プププランドで暮らす丸い体のゲームキャラクターは誰でしょう？

## Q000387 アニメ＆ゲーム / 難易度2

黒猫ルナと出会った月野うさぎが仲間たちと戦う、武内直子の漫画を原作とする変身ヒロインアニメは何でしょう？

答え：美少女戦士セーラームーン（びしょうじょせんしせーらーむーん）

月野うさぎはセーラームーンに変身し、水野亜美や火野レイらの仲間とともに戦います。

## Q000388 アニメ＆ゲーム / 難易度2

ゲームボーイ向けに発売された第1作ではデデデ大王に立ち向かう、敵を吸い込む丸い主人公の名前を冠したゲームは何でしょう？

1992年に発売されたアクションゲームです。コピー能力は続編『星のカービィ 夢の泉の物語』で登場しました。

## Q000389 アニメ＆ゲーム / 難易度3

妖怪が見える少年が、祖母レイコの遺品に記された名前を妖怪たちへ返していく、緑川ゆきの漫画を原作とするアニメは何でしょう？

主人公は夏目貴志。用心棒を自称するニャンコ先生とともに、妖怪や人々と関わります。

## Q000390 アニメ＆ゲーム / 難易度4

地下世界に落ちた人間がモンスターと出会う、敵を倒さずに戦闘を終える選択もできるトビー・フォックス制作のRPGは何でしょう？

答え：UNDERTALE（あんだーてーる）

戦闘では弾を避ける操作があり、プレイヤーの行動によって物語の展開が変わります。

## Q000391 文系 / 難易度1

## Q000392 文系 / 難易度2

宮中での生活などを記した『紫式部日記』も残しています。

## Q000393 文系 / 難易度2

## Q000394 文系 / 難易度3

答え：点描（てんびょう）

線や広い色面だけでなく、小さな色点の集まりで形や色彩を表現します。

## Q000395 文系 / 難易度4

似ているものにたとえる隠喩とは区別され、英語ではメトニミーといいます。

## Q000396 理系 / 難易度1

ヒトの胸の中にあり、内部の小さな袋で血液に酸素を取り込み、血液中の二酸化炭素を放出する呼吸器官は何でしょう？

答え：肺（はい）

内部には肺胞があり、その周囲を取り巻く毛細血管との間でガス交換を行います。

## Q000397 理系 / 難易度2

ニュートンの運動の第1法則に関わる性質で、質量が大きいほど運動状態を変えにくくなります。

## Q000398 理系 / 難易度2

ドライアイスが気体の二酸化炭素になるときのように、物質が液体を経ずに固体から直接気体へ変化する現象は何でしょう？

答え：昇華（しょうか）

逆向きの気体から固体への変化は、凝華と呼んで区別することがあります。

## Q000399 理系 / 難易度3

答え：不整合（ふせいごう）

境界の面は不整合面といい、地質時代の記録に欠けた期間があることを示します。

## Q000400 理系 / 難易度4

答え：二分探索（にぶんたんさく）

データ数をnとすると、比較回数は最悪の場合でもおおむねlog nに比例します。

## Q000401 生活 / 難易度1

## Q000402 生活 / 難易度2

## Q000403 生活 / 難易度2

## Q000404 生活 / 難易度3

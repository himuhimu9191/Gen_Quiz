# バッチ020：辞書見出しによる代表読みの校正

2026-11-03。全7,000問の代表読みを辞書読みと比較し、差分のうち同一見出しを確認できた語を個別に選んで、171問の代表読みを修正しました。設問全体の照合状態・分類・難易度・タグは保持しています。

例：日時計「ひどけい」、軍艦巻「ぐんかんまき」、羽生結弦「はにゅうゆづる」、万城目学「まきめまなぶ」、役所広司「やくしょこうじ」、共観福音書「きょうかんふくいんしょ」。送り仮名の重複による誤読も修正しました。

Janomeとの差分641件から辞書ページを調べ、完全一致する見出し367件を得ました。保存読みとの相違199件のうち171件を校正しています。同形異義語、正しい異読、見出しの省略があるものは自動置換していません。読みの一致は、設問の事実・一意性・別名まで確認したことを意味しません。

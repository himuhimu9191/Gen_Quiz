## 制作の進め方

1. 既存問題と代表解答を確認し、小分類と正解対象を分散させて新規問題を執筆する。
2. 問題文・解説・代表表記・読み・許容表記を揃え、未照合分をcandidateで登録する。
3. 公式資料などの本文を実際に読み、全主張・対立候補・許容表記を照合してverifiedへ進める。
4. 人の審査者と日付を記録した問題だけをapprovedにする。公開用CSVは承認済みだけを出力する。
5. 追加ごとにCSVを再出力し、テスト・構造検証・既存データ不変の確認を行う。
6. 進捗を更新し、コミット・プッシュ後にリモートSHAを確認する。
